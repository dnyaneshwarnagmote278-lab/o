⚙️ How It Works

1. Webcam captures the hand.

2. Python/MediaPipe identifies the hand and counts fingers.

3. Python sends a number from 0 to 5 through USB serial.

4. Arduino receives the number.

5. Arduino switches the required LEDs through D2–D6.
